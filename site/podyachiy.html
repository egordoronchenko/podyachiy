Сервис для записей совещаний

Из записи совещания — протокол с поручениями

Загружаете видео или звук. Подьячий распознаёт речь, разделяет говорящих и пишет протокол: что решили, кто что должен сделать и к какому сроку.

Ставится у себя — на сервер или свой компьютер, одним контейнером Docker. Записи и протоколы хранятся там же.

Что умеет

От файла записи до таблицы поручений. Часовая запись обрабатывается за несколько минут.

  • Расшифровка с говорящими

    Текст с временем каждой реплики. Голоса разделены, имена подписываются.

  • Протокол по шаблону

    Кратко, участники, решения, задачи. Шаблоны правятся, можно завести свой тип записи.

  • Поручения со сроками

    Кто, что и к какому сроку. У каждого поручения — ссылка на момент записи.

  • Реестр поручений

    Задачи всех совещаний одной таблицей: отбор, отметка «выполнено», выгрузка в CSV.

  • Поиск и экспорт

    Поиск по всем протоколам и расшифровкам. Протокол скачивается в DOCX и PDF.

  • Папки и права

    Доступ выдаётся на папку. Войти можно под учётной записью домена.

  • ИИ-клиенты и API

    Ключи доступа и навык для Cursor, Claude Code, Codex. Для программ — API.

  • Учёт расходов

    Сколько стоила обработка: по папкам, людям, записям и периодам.

  • Правка протокола

    Текст поправляется прямо на странице. Прежние версии сохраняются, вернуть — одной кнопкой.

  • Напоминания и календарь

    Раз в день — письмо о поручениях со сроком сегодня, завтра и просроченных. Сроки — в календарь (ICS).

  • Корзина и копии

    Удалённое возвращается кнопкой. Резервная копия — по расписанию из самого сервиса.

  • Webhook

    Учётная система узнаёт о готовой записи сама: сервис присылает ей подписанное уведомление.

Как устроено и куда идут данные

Сервис работает у вас. Распознаёт речь и пишет текст не он сам, а внешние модели — по вашему ключу.

  1. Запись

    Видео или звук загружается через страницу в браузере. Исходный файл не меняется.

    остаётся у вас

  2. Распознавание

    Модель возвращает текст, время каждого слова и метки голосов.

    звук уходит поставщику

  3. Протокол и поручения

    Текстовая модель пишет протокол по шаблону и выписывает поручения.

    расшифровка уходит поставщику

  4. Реестр, поиск, экспорт

    Результат лежит на вашем диске обычными файлами: текст, Markdown, JSON, mp3.

    остаётся у вас

Остаётся у вас

  • Сам сервис — контейнер Docker на вашем сервере или компьютере.
  • Записи, звук, расшифровки и протоколы.
  • Пользователи, права, журнал действий.
  • Ключ поставщика моделей — он ваш.

Уходит наружу

  • Звук записи — на распознавание.
  • Текст расшифровки — на протокол и поручения.
  • Получатель — поставщик, которого выбрали вы: OpenRouter или RouterAI. От него данные идут владельцам моделей.

Локальной обработки нет. Без связи с поставщиком новые записи не обрабатываются. Готовые протоколы открываются и без интернета. Если записи нельзя передавать наружу, сервис не подойдёт.

Протокол пишет модель, и она ошибается. Поэтому у каждого решения и поручения стоит ссылка на момент записи — важное стоит сверить. Автору сервис ничего не отправляет.

Два режима

Расшифровка, протокол, поручения, поиск и экспорт есть в обоих. Режим выбирается при установке.

Для одного человека

Личный

  • Стоит на своём компьютере.
  • Входа нет: открыл страницу и работаешь.
  • Все записи видны сразу.
  • Доступен только с этого компьютера.

Для организации

Корпоративный

  • Стоит на сервере во внутренней сети.
  • Вход обязателен: свой пароль или учётная запись домена.
  • Папки с правами: чтение и администрирование.
  • Чужая запись не видна — ни в списке, ни в поиске, ни по ссылке.
  • Заявки на доступ, журнал действий, ключи для ИИ-клиентов.

За час записи — поставщику

Распознавание и текст оплачиваете вы, напрямую поставщику моделей, по своему ключу. Замер — октябрь 2026 года, цены поставщиков меняются.

Что нужно для запуска

  • Docker — на Windows или Linux.
  • Ключ OpenRouter или RouterAI.
  • 2 ядра и 4 ГБ памяти. Видеокарта не нужна.
  • Интернет — для связи с поставщиком.

Сервис делает один разработчик. По лицензии MIT он поставляется как есть, без гарантий.
