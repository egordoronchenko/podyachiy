# Словарь: термины, фамилии и названия систем, которые звучат на ваших
# совещаниях, — так, как они должны быть написаны в протоколе.
#
# Распознавание речи их коверкает («СКУД» слышит как «scood»). Словарь уходит
# текстовой модели, которая делает разбор записи, выписывает поручения и пишет
# протокол: слово, по звучанию и смыслу похожее на термин из словаря, она пишет
# как в словаре. Готовая расшифровка и субтитры при этом не правятся.
#
# Самому распознаванию словарь подсказывает термины только у модели, которая
# принимает подсказки (сейчас это Microsoft MAI-Transcribe 2): ей термины
# уходят списком — по одному на запятую или строку. Остальным моделям
# распознавания подсказать термины нельзя.
#
# Строки, начинающиеся с решётки, в модель не попадают: здесь можно писать
# пояснения для коллег. Всё остальное уходит как есть.
#
# Правила:
#   - пишите слова ровно так, как они должны выглядеть в протоколе;
#   - НЕ пишите сюда выдуманные фамилии «для примера»: модель воспримет их как
#     вероятные и подставит вместо созвучных настоящих;
#   - вписывайте фамилии только тех, кто реально бывает на этих совещаниях.
#
# Это общий словарь — на все записи сервиса. Участников и сокращения одного отдела или
# одного совещания удобнее вписать в словарь папки или записи: кнопка «Словарь» в папке
# и в открытой записи. Тот словарь дополняет этот, а при совпадении побеждает.
#
# Файл читается заново перед каждым заданием — правка действует сразу,
# без перезапуска контейнера. Править его можно и на странице сервиса:
# «Управление → Настройки → Шаблоны и словарь».
