# Как помочь проекту

Сервис делает один человек в свободное время. Сообщения об ошибках и правки приветствуются,
но срок ответа не гарантируется.

## Сообщить об ошибке

Заведите задачу (issue) в репозитории. Приложите сведения, которые копирует кнопка в разделе
«О сервисе» (версия, режим, модель распознавания, браузер), и шаги, по которым ошибка
повторяется. Записи совещаний, протоколы, пароли и ключи не прикладывайте.

Об уязвимостях — не в issues, а письмом: см. [SECURITY.md](SECURITY.md).

## Предложить правку

1. Сделайте ответвление репозитория (fork) и ветку от `master`.
2. Внесите правку. Для нового поведения добавьте тест в `tests/`.
3. Проверьте:

   ```bash
   python -m compileall -q app
   docker build -t podyachiy:dev .
   docker run --rm -v "$PWD:/w" -w /w podyachiy:dev \
     sh -c "pip install -q -r requirements-dev.txt && python -m pytest -q -p no:cacheprovider"
   ```

4. Откройте запрос на слияние (pull request) с коротким описанием: что меняется и зачем.

## Правила кода

- Python 3.12, без отдельного сервера баз данных: состояние — один файл SQLite (`app/db.py`).
- Страницы — обычные HTML, CSS и JavaScript в `app/static`, без сборки и без внешних библиотек.
  Сценарий страницы — отдельным файлом `app/static/<страница>.js`: встроенные `<script>` и
  обработчики `on…=` в разметке и в строках `innerHTML` запрещает заголовок Content-Security-Policy
  сервиса, и тест `tests/test_security.py` их не пропустит. Обработчики — через `addEventListener`
  или свойства `onclick` в сценарии.
- Одна реализация вместо двух: запасных путей «на всякий случай» и выключателей для старого
  поведения в коде нет.
- Новый адрес API нужно назвать в списках `tests/test_web.py` (открытые, только администратору,
  только со страницы) — иначе тесты не пройдут.
- Тесты наружу не ходят: поставщики моделей, почта и домен заменены заглушками.
- В тестах и примерах — только вымышленные люди, организации и записи.
- Тексты интерфейса и документации — на русском.

Отправляя правку, вы соглашаетесь, что она распространяется на условиях лицензии MIT —
см. [LICENSE](LICENSE).
