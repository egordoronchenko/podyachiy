# Установка навыка «Подьячий»

Этот текст — для ИИ-клиента (Claude Code, Cursor, Codex, DeepSeek Harness и подобных).
Выполни шаги по порядку командами в терминале и скажи человеку то, что написано в шаге 4.

«Подьячий» ({{URL}}) — сервис записей совещаний: хранит записи, их протоколы,
расшифровки и поручения. Навык учит тебя находить и читать протоколы, собирать
поручения и загружать новые записи — запросами `curl` от имени человека.

{{#corporate}}
Главное правило: **не проси человека вставить пароль или ключ в чат** и не выводи их.
Человек сам вписывает ключ в файл на своём компьютере.
{{/corporate}}
{{#personal}}
Сервис работает в личном режиме, без входа: ни ключа, ни пароля не нужно — не спрашивай их.
{{/personal}}

## 1. Скачай навык

Навык — один файл `SKILL.md`. Скачивай его `curl`-ом: встроенные средства чтения
страниц до адреса во внутренней сети обычно не достают. Куда положить:

| Клиент | Папка |
|---|---|
| Claude Code | `~/.claude/skills/podyachiy/` |
| Codex, Cursor, DeepSeek Harness, Gemini CLI, GitHub Copilot и остальные | `~/.agents/skills/podyachiy/` |

`~` — домашняя папка пользователя; в Windows это `%USERPROFILE%`. Не знаешь, какой ты
клиент, — положи в обе папки. Существующий `SKILL.md` в папке `podyachiy` замени: это
обновление навыка (версия {{VERSION}}; дальше навык обновляет себя сам). Другие папки не трогай.

Bash (Linux, macOS, Git Bash) — для Claude Code:

```bash
d="$HOME/.claude/skills/podyachiy"; mkdir -p "$d" && curl -fsS "{{URL}}/skill/SKILL.md" -o "$d/SKILL.md" && head -n 2 "$d/SKILL.md"
```

Для остальных клиентов — то же с `d="$HOME/.agents/skills/podyachiy"`.

PowerShell (Windows; именно `curl.exe`) — для Claude Code:

```powershell
$d = "$HOME\.claude\skills\podyachiy"; New-Item -ItemType Directory -Force $d | Out-Null; curl.exe -fsS "{{URL}}/skill/SKILL.md" -o "$d\SKILL.md"; Get-Content "$d\SKILL.md" -TotalCount 2
```

Для остальных клиентов — то же с `$d = "$HOME\.agents\skills\podyachiy"`.

Проверка: первые строки файла — `---` и `name: podyachiy`.

Если `curl` не достучался до сервера (`curl: (7)`, `(28)`), сеть закрыта песочницей клиента:

- **Codex** — попроси разрешить команде доступ в сеть или включить его насовсем:
  в файле `~/.codex/config.toml` в разделе `[sandbox_workspace_write]` строка `network_access = true`.
- **Cursor** — попроси разрешить запуск команды вне песочницы или добавить адрес в
  `~/.cursor/sandbox.json`: `{"networkPolicy": {"allow": ["{{HOST}}"]}}`.
{{#corporate}}
- Иначе человек не во внутренней сети организации (нужен VPN) или сервис остановлен.
{{/corporate}}
{{#personal}}
- Иначе сервис остановлен: запусти его — `docker compose start` в папке установки.
{{/personal}}

Эти файлы настроек сам не правь — скажи человеку, что и где включить.

{{#corporate}}
## 2. Создай файл с учётными данными

Один файл в домашней папке: `~/.podyachiy`. Если он уже есть — **не трогай**: в нём
ключ человека. Нет — создай с адресом сервиса и пустыми полями.

Bash:

```bash
[ -e "$HOME/.podyachiy" ] || { printf '# Podyachiy\nurl={{URL}}\nkey=\nlogin=\npassword=\n' > "$HOME/.podyachiy"; chmod 600 "$HOME/.podyachiy"; }
```

PowerShell:

```powershell
$f = "$HOME\.podyachiy"; if (-not (Test-Path $f)) { [IO.File]::WriteAllLines($f, @("# Podyachiy", "url={{URL}}", "key=", "login=", "password=")) }
```

Содержимое существующего файла не выводи.

## 3. Ничего больше не делай

Не ищи ключ, не спрашивай пароль, не создавай переменных окружения, не меняй настройки клиента.

## 4. Скажи человеку

Передай ему это своими словами, по-русски:

> Навык «Подьячий» установлен. Осталось подключить его к сервису — это делаете вы сами, мне ключ или пароль присылать не нужно. Есть два способа:
>
> **Ключ доступа (лучше).** Его можно отозвать в любой момент, пароль при этом не меняется, и войти с ним на страницу сервиса нельзя.
> 1. Откройте {{URL}}/#keys и войдите — откроется окно «Ключи доступа» (оно же в меню внизу слева). Назовите ключ (например, «Cursor на ноутбуке»), выберите срок и нажмите «Выпустить ключ». Ключ показывается один раз — скопируйте его.
> 2. Откройте в текстовом редакторе файл `.podyachiy` в своей домашней папке (в Windows — `C:\Users\<ваше имя>\.podyachiy`) и вставьте ключ после `key=`. Сохраните.
>
> **Логин и пароль.** В том же файле впишите их в строки `login=` и `password=`, а `key=` оставьте пустым. Так можно, только если учётную запись вам завели в самом сервисе. Если вы входите в сервис логином и паролем домена (теми же, что на рабочем компьютере) — выпустите ключ: доменный пароль в файл не вписывайте, сервис с ним программы не пускает.
>
> Потом начните новый разговор и попросите, например: «найди в Подьячем протокол последнего совещания», «какие на мне поручения» или коротко — `/podyachiy поручения`.

Назови человеку полный путь к файлу на его компьютере.

## 5. Проверка подключения

Когда человек скажет, что вписал ключ, выполни один запрос из раздела «Подключение»
файла `SKILL.md` — `whoami`. В ответе логин и имя человека — всё работает. Ответ
`401` — ключ не вписан, вписан с ошибкой или отозван: попроси человека проверить файл,
сам файл не выводи.
{{/corporate}}
{{#personal}}
## 2. Создай файл с адресом сервиса

Один файл в домашней папке: `~/.podyachiy`, в нём только адрес. Если он уже есть — не трогай.

Bash:

```bash
[ -e "$HOME/.podyachiy" ] || printf '# Podyachiy\nurl={{URL}}\n' > "$HOME/.podyachiy"
```

PowerShell:

```powershell
$f = "$HOME\.podyachiy"; if (-not (Test-Path $f)) { [IO.File]::WriteAllLines($f, @("# Podyachiy", "url={{URL}}")) }
```

## 3. Проверь подключение

Выполни один запрос из раздела «Подключение» файла `SKILL.md` — `whoami`. Ответ с
`"login": "owner"` — всё работает.

## 4. Скажи человеку

> Навык «Подьячий» установлен и подключён: сервис работает без входа, ключ не нужен. Начните новый разговор и попросите, например: «найди в Подьячем протокол последнего совещания», «какие поручения не закрыты» или коротко — `/podyachiy записи`.
{{/personal}}
