# Подьячий: возможности

Что сервис делает с записью, что ещё умеет, чем отличаются режимы и чего от него ждать не стоит.
Как этим пользоваться — [руководство пользователя](guide/README.md); как поставить —
[инструкция по установке](../install/README.md).

## Что делает с записью

1. Принимает запись — видео или звук, файлом до 4 ГБ, через страницу (с докачкой после обрыва),
   через API или из папки на диске.
2. Извлекает звук и отправляет его на распознавание: модель возвращает текст, время каждого
   слова и метку говорящего.
3. Определяет тип записи — совещание, лекция, созвон с заказчиком, постановка задачи — и пишет
   протокол по шаблону этого типа. У каждого решения и каждой задачи стоит метка времени:
   щелчок по ней перематывает запись на нужное место.
4. Для совещаний поручения выписывают несколько моделей независимо — так их теряется меньше.
5. Строит карту протокола; протокол, карта и расшифровка скачиваются одним HTML-файлом.

## Что ещё есть

- **Реестр поручений** по всем совещаниям: отметка «выполнено», сроки, выгрузка в CSV и в календарь
  (ICS). Раз в день — письмо с напоминанием о сроках: что просрочено, что сегодня и завтра.
- **Правка протокола** текстом прямо на странице, без модели и бесплатно. Прежние тексты — в версиях:
  их можно посмотреть и вернуть.
- **Поручения прошлого совещания.** Незакрытые поручения предыдущей записи — в конце нового
  протокола, в папках, отмеченных как серия совещаний.
- **Поиск** по протоколам и расшифровкам.
- **Экспорт** протокола в DOCX и PDF.
- **Подписи говорящих** вручную: людей по голосу сервис не узнаёт. Подписанное ФИО само попадает в
  словарь папки.
- **Свои шаблоны протоколов, свои типы записей и словарь терминов.**
- **Словарь участников и сокращений** на папку и на отдельную запись: по нему в протоколе стоят
  полные ФИО и правильные сокращения.
- **Почта:** письмо «запись готова», напоминания о сроках поручений и отправка протокола на почту.
- **Webhook «запись готова»:** внешняя система (1С, трекер задач) узнаёт о готовой записи сама.
- **Корзина:** удалённая запись или папка 30 дней возвращается кнопкой — со всем, что у неё было.
- **Резервная копия** всей установки одним архивом — по расписанию из самого сервиса или командой.
- **Отчёт о расходах** по папкам, людям и записям — на странице и файлом Excel, CSV или PDF.
  Видит его только администратор сервиса.
- **Светлая и тёмная тема.**

Шаблоны, словарь и логотип организации правятся на странице «Управление → Настройки»
([шаблоны, словарь и оформление](../install/README.md#7а-шаблоны-словарь-и-оформление)). Остальные
настройки — в файле `.env`: образец с пояснениями — [install/.env.example](../install/.env.example),
описание каждой строки — [«Настройки `.env`»](../install/README.md#3-настройки-env).

## Два режима

Режим задаётся строкой `MODE` в `.env`.

| | Корпоративный — `MODE=corporate` | Личный — `MODE=personal` |
|---|---|---|
| Для кого | организация, несколько человек | один человек на своём компьютере |
| Вход | обязателен | нет |
| Папки и права | у каждого личная папка; общие папки с раздельными правами: чтение, загрузка, администрирование | все записи видны сразу |
| Заявки на доступ, почта, ключи доступа | есть | нет |
| Вход через домен, свой логотип | есть | нет |
| Доступ по сети | во внутренней сети | **нельзя**: сервис отдаст всё любому, кто до него достанет |

Подробнее — [«Режимы»](../install/README.md#4-режимы-mode) в инструкции по установке.

## Вход через домен

В корпоративном режиме люди могут входить логином и паролем домена (Active Directory): сервис
проверяет их у контроллера домена по LDAPS и при первом входе сам заводит человека. Кого пускать
и кто администратор, решают группы домена. Работает только по HTTPS. Проверено на контроллере
Samba 4; на Active Directory под Windows Server не проверялось. Настройка —
[«Вход через домен»](../install/README.md#10а-вход-через-домен-active-directory).

## Поставщик моделей и цена

Сервис ходит к моделям через шлюз с OpenAI-совместимым API: OpenRouter (оплата в долларах) или
RouterAI (в рублях). Достаточно одного; второй можно задать запасным — сервис перейдёт на него,
если основной не отвечает. Адреса и ключи —
[«Модели и поставщики»](../install/README.md#модели-и-поставщики).

Ориентир по ценам из карточек моделей: на модели распознавания по умолчанию
(`elevenlabs/scribe-v2`) час записи стоит порядка 0,15–0,25 $ через OpenRouter или 17–30 ₽ через
RouterAI; большая часть суммы — распознавание речи. Цены поставщики меняют — сверяйте в их
карточках моделей. Сколько стоила каждая запись, сервис показывает администратору в разделах
«Обработка» и «Расходы»; остальным пользователям суммы не показываются. Подробно и сколько нужно
места на диске — [«Что это и что нужно»](../install/README.md#1-что-это-и-что-нужно).

## Программы и ИИ-клиенты

Всё, что видно на странице, доступно запросами `/api/v1/…`. Для ИИ-клиентов с терминалом
(Claude Code, Cursor, Codex) есть навык: человек просит обычными словами — «найди протокол
вчерашней планёрки», «какие поручения на мне не закрыты». Подробно —
[интеграция с ИИ-клиентами и программами](integration.md).

## Ограничения

- **Данные уходят поставщику моделей.** Звук и текст записей отправляются выбранному вами
  поставщику и дальше — владельцам моделей, чьи серверы находятся за границей. Если правила
  организации это запрещают, сервис не подойдёт.
- **Говорящих разделяет модель и ошибается.** Чем больше людей и чем длиннее запись, тем чаще
  реплика достаётся не тому. Людей по голосу сервис не узнаёт: имена он берёт из разговора как
  догадку, остальных подписывает человек.
- **Протокол пишет языковая модель.** Поручения иногда теряются, фамилии и термины искажаются.
  Важное сверяют по записи — для этого у решений и задач стоят метки времени.
- **Для внутренней сети.** На публикацию в интернете сервис не рассчитан: двухфакторного входа
  нет. По HTTP пароли идут открыто — для шифрования перед сервисом ставится прокси.
- **Интерфейс и шаблоны — на русском.**
- **Поддержки нет.** Сервис делает один человек в свободное время и распространяет его «как есть»,
  без гарантий.

Что ещё сервис не делает (копии за пределы сервера, удаление по сроку, вход без пароля) —
[«Чего сервис не делает»](../install/README.md#16-чего-сервис-не-делает).
